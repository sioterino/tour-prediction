OVERVIEW

What is STAGELINE?

STAGELINE is a machine learning tool that predicts concert attendance for K-pop world tour shows. Given an artist, a venue, and a show date, it returns a single number: the estimated number of people expected to attend.

It is not a forecasting product. It is a research tool built on historical tour data, designed to give a data-backed starting point for capacity planning, routing decisions, or market sizing.

HOW IT WORKS

The pipeline

From raw data to prediction, five steps:

1
DATA COLLECTION
Historical tour records are assembled from public and reported sources. Each row represents one show leg — a specific artist at a specific venue for a number of nights.
2
FEATURE ENGINEERING
Raw records are enriched: debut date → years since debut → artist age bucket. Leaky columns (fill rate, box score, avg ticket price) are removed — they would only be known after the show, not before.
3
EXPERIMENT SELECTION
Six dataset variants and three model types (Linear Regression, Random Forest, Gradient Boosting) are trained and evaluated. The combination with the lowest MAE is selected automatically.
4
TRAINING
The winning model is retrained on all available labelled data (reported shows only), then exported as a bundle: model weights + fitted scaler + encoded column list.
5
INFERENCE
The frontend collects your inputs, computes derived fields locally, and sends a single POST request to the API. The API preprocesses the row identically to training and returns a rounded attendance estimate.

How accurate is it?

⚠ IMPORTANT CONTEXT

An MAE of 4,120 means very different things depending on venue size. For a 55,000-seat stadium that's a ~7% margin — useful. For an 8,000-seat arena it's a ~50% swing — treat the number as a rough order of magnitude, not a booking guarantee.

The model has only seen K-pop world tour data. Predictions for artists, venues, or markets underrepresented in that dataset will be less reliable. It has no knowledge of ticket sales, marketing spend, tour announcement timing, or external events.
